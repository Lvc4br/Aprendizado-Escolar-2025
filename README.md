# Aprendizado Escolar — 2025

Projeto acadêmico estático para praticar a recriação de uma página de concessionária de veículos, com conteúdo visual relacionado à Honda/Motofield. É um exercício de front-end, não um site oficial nem uma aplicação conectada aos sistemas de uma concessionária.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: layout e estilos.
- `app.js`: menu, efeito sticky e carrossel de imagens.

## Execução

Abra `index.html` em um navegador ou sirva a pasta por HTTP. Não há processo npm, backend ou build documentado. A página carrega bibliotecas de ícones por CDN; esses recursos externos precisam estar acessíveis para aparecerem.

## Estado e limitações

- Exercício acadêmico estático, sem API, autenticação ou persistência.
- Não há testes automatizados, lint ou CI configurados.
- O JavaScript verifica se os elementos de menu e slider existem antes de usá-los; o slider automático só é ativado quando há mais de um item.
- Confira os links, os direitos de uso de imagens/logos e a disponibilidade dos recursos externos antes de publicar ou reutilizar o projeto.
